# Hard-Time
Modern source port of MDickie's 2007 prison sim - Hard Time.
Made with Raylib + Odin to recreate the classic Blitz3D API.

### Goals
Make the game's source and assets readily available for fans and modders. Preserving it for decades to come. Ported to a simple low level language with a trivial build system (Odin), and a cross-platform graphical library with a supportive community (Raylib).
